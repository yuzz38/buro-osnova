# buro OSNOVA: лендинг

Одностраничный сайт рекламного бюро buro OSNOVA (Костанай): полиграфия, бренд-упаковка, рельефные печати, ленты, тишью, подарочные сертификаты.

## Структура
```
index.html          — страница (11 блоков)
css/style.css       — стили
js/main.js          — скрипты (без библиотек)
assets/img/         — изображения WebP (480/960) + JPEG-запас
assets/video/       — видео-петли MP4 (H.264, без звука) + постеры WebP
assets/favicon.svg, apple-touch-icon.png, icon-192/512.png
site.webmanifest, robots.txt, sitemap.xml, llms.txt, .htaccess
SEO.md              — семантическое ядро и чек-лист запуска
```

## Блоки
1. Первый экран: «печатный лист» с метками реза, видео и печатью-бейджем
2. Услуги: карточки-образцы материалов, переворачиваются
3. Бренд-упаковка: видео тишью, УФ DTF, наклеек, тиснения, штампа
4. Цены с переключателем ₸ / ₽
5. Интерактивный подарочный сертификат buro OSNOVA: наклон, фольга, конверт из кальки, сургуч
6. Предзаказ лент: палитра цветов, кнопка «ЛЕНТА» в WhatsApp с выбранным цветом
7. Конструктор фирменного комплекта: готовый список уходит в WhatsApp
8. Работы с просмотром фото
9. Отзывы: слайдер (свайп, стрелки, точки, автопрокрутка)
10. FAQ
11. Контакты и Яндекс.Карта

## Технически
- Адаптив от 320 px, бургер-меню на мобильных, нижняя панель «Позвонить / WhatsApp».
- iOS Safari и Android Chrome: `safe-area-inset`, `playsinline`, `100svh`, поля ввода 16 px без автозума.
- `prefers-reduced-motion` учитывается.
- Подключение: просто загрузить содержимое папки в корень хостинга.

## Перед публикацией
- **Отзывы в блоке 9 демонстрационные.** Заменить их на реальные отзывы клиентов (Instagram, 2ГИС), а затем удалить подпись под слайдером.
- Указать реальный домен и проверить координаты и часы работы (см. SEO.md).
